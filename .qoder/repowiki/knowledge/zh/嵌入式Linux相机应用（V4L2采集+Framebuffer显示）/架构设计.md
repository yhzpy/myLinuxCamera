项目采用分层模块化架构：顶层 main.c 作为入口协调各模块；video/ 层封装 V4L2 设备抽象（v4l2.c + video_manager.c），通过 T_VideoOpr 接口注册驱动并管理缓冲区；display/ 层封装 Framebuffer 显示（fb.c + disp_manager.c），提供 T_DispOpr 接口和 VideoMem 缓冲机制；convert/ 层实现 YUV/MJPEG/RGB 之间的格式转换（yuv2rgb/mjpeg2rgb/rgb2rgb/color），由 convert_manager 统一注册与选择；render/operation 提供 PicZoom/PicMerge 等像素级图像处理。依赖方向严格自上而下：main → 管理器 → 具体驱动/算法，各模块通过函数指针表（如 T_VideoOpr、T_VideoConvert）解耦，支持多设备/多转换器插件式扩展。主循环遵循 GetFrame → Convert → PicZoom → PicMerge → FlushPixelDatasToDev → PutFrame 的标准处理流水线。
